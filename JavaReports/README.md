# JavaReports

Десктопний застосунок звітів автосервісу. Для запуску потрібні JDK 25 і Maven.

У корені репозиторію заповни `.env` за зразком `.env.example`. Застосунок використовує спільний `APP_DB_USER` та `APP_DB_PASSWORD`.

Windows: `JavaReports\run.bat`

Linux/macOS: `bash JavaReports/run.sh`

Увійди обліковим записом працівника з роллю `director`. Звіти можна фільтрувати за датами та експортувати в PDF.
